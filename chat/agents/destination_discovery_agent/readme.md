## Destination Discovery Agent

** Helps users discover and choose the right travel destination before itinerary planning begins.**

The Destination Discovery Agent helps travelers find, compare, and understand travel 
destinations based on their preferences, budget, interests, and trip style. 
It recommends suitable destinations, highlights top attractions, activities, and 
local cuisines, answers destination-specific questions, and transfers users to the 
Planning Agent once they choose where they want to go.
